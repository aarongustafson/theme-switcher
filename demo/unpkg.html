Postpublication import-map example

This page displays source only. It doesn’t execute the import map or registration module, or render a live picker. After the referenced versions are published, use an import map to resolve the base package before loading the registration module: 

<script type="importmap">
{
  "imports": {
    "@aarongustafson/form-multi-switch":
      "https://unpkg.com/@aarongustafson/form-multi-switch@1.0.0/index.js"
  }
}
</script>
<script type="module"
  src="https://unpkg.com/@aarongustafson/theme-switcher@1.0.1/define.js">
</script>
<theme-switcher label="Color theme">
</theme-switcher>

Use the working local demos. The generated control shown in this source has no native fallback before upgrade.
